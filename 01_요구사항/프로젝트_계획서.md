## 3. 연결 요구사항

- 부서 사이: 부서별로 네트워크를 나누어 관리한다. 디자인팀은 인사팀과 통신 할 일이 없어 통신하지 않아도 됌. 각 부서는 필요한 업무 서버에만 접속할 수 있도록 한다.
- 본사와 지사 사이: 대구 본사와 서울 지사를 라우터를 이용해 연결한다. 본사와 지사는 VPN망을 이용해 안전하게 데이터를 주고 받을 수 있도록 한다.지사의 영업팀에서는 본사의 주문 관리 서버와 파일 서버에 접근 가능 해야 한다.
- 인터넷: 디자인팀에서는 일반 PC는 인터넷 접속이 불가능하고 디자인팀 파일 서버를 통해서 디자인팀끼리 공유 할 수 있도록 한다. 지정된 1대의 PC만 인터넷 사용이 가능하도록 한다. 인터넷 전용 PC와 일반 PC는 서로 통신이 불가능해야한다.(디자인 유출을 막기 위해서). 지사의 모든 직원이 인터넷을 사용할 수 있도록 구성한다. 
- 밖에서 들어오는 접속: 외부 고객이 인터넷을 통해 루아패션 쇼핑몰 웹 서버에 접속할 수 있도록 한다. 쇼핑몰 웹 서버는 DMZ 영역을 배치하여 내부 업무망과 분리한다. 
- 재택 근무: 재택근무자는 외부에서 본사 내부망에 접속하여 쇼핑몰 웹 서버를 관리할 수 있도록 한다. 

## 4. 지킬 것과 걱정되는 것

| 지킬 것 | 깨지면 안 되는 것 (기밀성, 무결성, 가용성) | 무엇이 잘못될 수 있나 |
|---------|--------------------------------------------|------------------------|
| 고객 개인정보 | 기밀성 | 고객의 이름, 주소, 전화번호가 외부로 유출될 수 있음 |
| 직원 급여 자료 | 기밀성 | 직원의 급여 정보가 다른 사람에게 공개될 수 있음 |
| 주문 내역 | 무결성 | 주문 수량이나 배송 정보가 임의로 변경될 수 있음 |
| 쇼핑몰 웹 서버 | 가용성 | 서버에 문제가 발생하여 쇼핑몰 접속이 중단될 수 있음 |
| 디자인 자료 | 기밀성 | 신상품 디자인과 자료가 외부로 유출될 수 있음 |
| 파일 서버 자료 | 무결성 | 업무 파일이 삭제되거나 잘못 수정될 수 있음 |
| 네트워크 장비 설정 | 무결성 | 라우터와 스위치 설정이 잘못 변경될 수 있음 |
