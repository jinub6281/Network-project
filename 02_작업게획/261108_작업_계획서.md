# 4일차 작업 계획서

- 날짜: 2026.11.08

## 1. 목표

- 프로젝트 계획서 3번 칸의 "지사 영업팀은 본사의 주문 관리와 파일 서버를 쓴다"를 이룬다
- 본사와 지사 사이 회선 하나가 끊겨도 지사가 멈추지 않게 한다 (계획서 4번 칸의 가용성)

## 2. 작업 대상

| 대상 | 무엇을 |
|------|--------|
| BR-R1, BR-SW1 (새로) | 기본 잠금, 스위치 보안, 지사 영업팀 주소             |
| HQ-R1              | Gi0/1 주 회선, Se0/0/0 예비 회선, 지사로 가는 경로 |
| 두 라우터              | HWIC-2T 시리얼 모듈                       |


## 3. 작업 내용

1. 지사 장비를 놓고 잠근다
2. 주 회선 192.168.99.0/24으로 두 라우터를 잇는다
3. 본사에 지사로 가는 정적 경로, 지사에 기본 경로를 넣는다
4. 두 라우터에 시리얼 모듈을 꽂고 예비 회선 192.168.100./24을 잇는다
5. 관리 거리 250의 예비 경로를 넣는다
6. 주 회선을 끊어 장애 시험을 한다

## 4. 확인 방법

| 확인할 것 | 방법 | 기대하는 결과 |
|-----------|------|---------------|
| 두 라우터가 이어졌다 | BR-R1에서 `ping 192.168.99.1`           | Reply                           |
| 지사에서 본사로 간다 | BR-PC1에서 `tracert 192.168.10.1`      | 세 칸                             |
| 경로가 들어갔다    | `show ip route static`                | 본사 S, 지사 S*                     |
| 예비 회선이 이어졌다 | HQ-R1에서 `ping 192.168.100.2`           | Reply                           |
| 장애 때 넘어간다   | 본사 Gi0/1 shutdown 중 BR-PC1의 `ping -t` | 몇 개 빠진 뒤 다시 Reply, 경로표에 [250/0] |

## 5. 되돌리는 방법

- 모듈을 꽂기 전에 반드시 저장한다. 꽂은 뒤 설정이 비면 저장한 설정으로 부팅된다
- 경로를 잘못 넣었으면 같은 줄 앞에 `no` 를 붙여 지운다
- 장애 시험 뒤에는 반드시 `no shutdown` 으로 주 회선을 살린다
