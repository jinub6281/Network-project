# 1일차 작업 계획서

- 날짜: 2026.11.01

## 1. 목표

- 각 부서에 네트워크 통신이 가능하도록 IP 할당 및 서브넷팅

## 2. 작업 대상

| 대상 | 무엇을 |
|------|--------|
|전체|PC의 IP 할당 작업|

## 3. 작업 내용

1. 각 부서별 PC IP 할당을 통해 PC간 데이터 통신이 가능하게 만든다.
2. 기존 부서별 IP 주소를 서브네팅 방식에 맞게 변경한다.
3. 192.168.10.0/24 네트워크를 4개의 /26 서브넷으로 분할한다
4. 모든 PC의 서브넷 주소를 255.255.255.192로 설정한다
5. 각 부서의 브로드캐스트 주소로 Ping을 전송하여 내부 통신을 확인한다
6. 다른 부서의 PC로 Ping을 전송하여 서로 다른 서브넷 간 통신 결과를 확인한다.

## 4. 확인 방법

| 확인할 것 | 방법 | 기대하는 결과 |
|-----------|------|---------------|
|PC의 IP 할당 상태|다른 PC의 IP를 활동해 Ping 패킷을 보내고 받는다.|모든 Ping 패킷 신호가 정상적으로 수신 및 발신이 가능하다|
|각 부서 내부에서 통신|네트워크의 브로드캐스트 IP로 Ping 브로드캐스트|같은 서브넷의 PC들이 응답한다.
|다른 부서와의 통신|영업팀 PC에서 IT개발팀 PC로 Ping 전송

## 5. 되돌리는 방법

-PC의 IP 할당 정보를 초기화한다.
-작업 전 저장된 패킷트레이서 파일을 불러온다.
